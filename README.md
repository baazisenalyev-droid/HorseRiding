# 🐎 Кони Кыргызстана — HorseRiding

Многостраничный сайт о катании на лошадях и лучших конных маршрутах в Кыргызстане (Тянь-Шань).

**Сайт полностью на русском языке**, живой, анимированный, с возможностью бронирования туров.

## ✨ Особенности

- **6 страниц**: Главная, Маршруты, Забронировать, Галерея, О проекте, Контакты
- Каждая страница содержит 5–8 смысловых секций
- Полностью адаптивный дизайн (Tailwind CSS)
- Плавные анимации (AOS + CSS)
- Интерактивная форма бронирования с предзаполнением маршрута из URL
- Модальное окно успеха + конфетти при бронировании
- Фильтруемая галерея с лайтбоксом
- Сохранение бронирований в localStorage (демо)
- Природа, горы, кочевая культура — тёплая цветовая палитра
- Реалистичные фото через picsum.photos + подписи

## 📁 Структура проекта

```
HorseRiding/
├── index.html          # Главная страница (7 секций)
├── routes.html         # Все маршруты + детальные описания
├── booking.html        # Форма бронирования + успех + предзаполнение ?route=
├── gallery.html        # Фотогалерея с фильтрами и лайтбоксом
├── about.html          # О проекте, культуре, команде, экологии
├── contact.html        # Контакты + форма + FAQ
└── README.md
```

## 🚀 Запуск локально

Просто откройте `index.html` в браузере.  
Или используйте любой локальный сервер:

```bash
# Python
python -m http.server 8000

# Или npx
npx serve
```

## 🌐 Развёртывание на GitHub Pages

1. Зайдите в настройки репозитория → **Pages**
2. Выберите ветку `main` и корневую папку `/ (root)`
3. Сохраните — сайт будет доступен по адресу:
   `https://baazisenalyev-droid.github.io/HorseRiding/`

## 📌 Как забронировать (демо)

- Перейдите на страницу **Забронировать**
- Или нажмите «Забронировать» на любом маршруте — параметр `?route=songkol` автоматически выберет нужный тур
- Заполните форму → нажмите отправить
- Появится красивое модальное окно с подтверждением + конфетти
